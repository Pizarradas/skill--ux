# UX Skill

Este archivo existe para entornos que cargan *skills* con front matter (p. ej. Claude).
**El sistema es agnóstico**: las instrucciones completas están en [`AGENTS.md`](AGENTS.md),
que es lo que debe seguir cualquier modelo.

1. Lee `AGENTS.md` (rol, carga progresiva, habilidades H1–H8, reglas R1–R10, formato).
2. Lee `00-indice/mapa-global.md`.
3. Carga sólo las fichas y guías que necesite la tarea.
